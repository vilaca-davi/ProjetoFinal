\# Reflexão sobre o curso



Neste trabalho, aprendi a usar commits para registrar cada mudança,

branches para organizar as etapas e pull requests para juntar as

alterações na main. Também aprendi a vincular um PR à Issue que ele resolve.



Uma dificuldade foi perceber que os três commits do bichinho virtual

e do CSS tinham ficado na minha main local. Usei o git log para localizar

esses commits e consegui levá-los para a branch feat/projetos sem refazer

o código. Em outros projetos, vou conferir a branch atual antes de começar

a editar.
